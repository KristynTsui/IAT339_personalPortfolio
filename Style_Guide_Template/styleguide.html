Navigation Button

CSS selector:

  • .nav-link

Sample code:

<a class="nav-link" href="#interactive_elements">Default Navigation Button</a>

Rendered element:

Default Navigation Button

In-text link

CSS selector:

  • .in-text-link

Sample code:

<p>Hello, my name is Kristyn, my portfolio can be found <a href="#interactive_elements">here</a> to browse.</p>

Rendered element:

Hello, my name is Kristyn, my portfolio can be found here to browse.
